## 🚀 Últimos proyectos

### 📋 Sistema de Tareas y Evidencias
Aplicación web para PC y teléfono (instalable como PWA) para asignar tareas a equipos y respaldarlas con evidencias.
- Roles: Administrador, Supervisor y Colaborador
- Subtareas, dependencias, tareas recurrentes y flujo de estados controlado
- Evidencias con ubicación GPS, guardadas de forma privada
- Notificaciones en la app y por correo, con recordatorios
- Dashboard con reportes exportables a Excel
- Auditoría de seguridad con 12 hallazgos corregidos

🔗 [Ver repositorio](https://github.com/LuisTobar765/sistema-tareas)

### 💰 Control de Pagos
Sistema para registrar boletas y facturas, enviarlas a aprobación y asociar sus comprobantes de pago.
- Estados: pendiente, aprobado, pagado, rechazado y no conciliado
- Abonos parciales, notas de crédito, IVA y retención de honorarios
- Búsqueda avanzada con reporte Excel, resumen general y ficha de proveedores
- Verificación en dos pasos (2FA), segregación de funciones e historial de auditoría

🔒 Repositorio privado

### 🤖 Laboratorio de Agentes
Bot de Telegram con IA que uso para aprender a construir agentes: herramientas, memoria, controles de calidad con pruebas automáticas y webhook con cola de trabajos.
